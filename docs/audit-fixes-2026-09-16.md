## 性能与模块边界

建立固定规模：3 个账户，每账户 100 只基金、10,000 条流水。先断言市值、持有收益、当日收益及流水数，再记录计算和编码耗时。发现每只基金都会扫描整份流水，改为一次按基金分组，场外账户也不再构建场内专用成交索引。

本机 Swift 6.4 Debug 单次观测（不作为 CI 时间阈值，也不等同于 UI 帧率）：

| 指标 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 三账户计算 | 0.841 秒 | 0.046 秒 |
| 三账户 JSON 编码 | 0.256 秒 | 0.253 秒 |
| 编码字节数 | 13,861,968 | 13,861,968 |

后续优化已实现：

- **行情持久化**：行情刷新在后台编码、计算账本摘要和写临时文件，回到主线程核对快照版本后原子提交。确认交易、份额和流水变化写完整账本；纯行情写 `portfolio-quotes.json`，不再每轮重写历史流水。同步财务操作保持立即保存；暂存刷新不能覆盖清空、导入或新交易。缓存绑定账本摘要，过期、损坏或财务字段不一致的缓存会被忽略。
- **多账户网络共享**：一次刷新按场内/场外分别收集去重代码，批量请求后分发给各账户；重复的账户级刷新合并到同一个任务。增加交易导致代码集变化时重新取数。正式历史净值按代码及精确日期共享 60 秒缓存，失败不缓存；详情补充数据共享 5 分钟缓存，两者都有容量上限和进行中请求合并。
- **视图派生缓存**：缓存归属于每个 PortfolioStore，以快照版本失效。基金分类、待确认活动和标题影响只构建一次，筛选与排序单独缓存，外观、弹窗状态等变化不再重复扫描流水。
- **全账户备份**：状态栏菜单提供“备份全部账户”“恢复全部账户”“撤销最近一次账户恢复”。保存账户类型、名称、选择、持仓、交易与收益历史；恢复前预览并自动保留原数据，恢复中断时先回滚。校验每个账户的独立目录、数据对应关系和版本；未恢复的日志会阻止普通保存及后台刷新。此备份覆盖当前账户，不包含登录 Cookie 或已归档账户。
- **模块拆分**：PortfolioStore 按持久化、刷新、确认、场内交易、份额、京东同步和流水拆分；状态栏菜单与窗口组件独立；持仓分布、排行榜、详情、流水、图表等视图各自成文件。所有 Store 扩展仍在同一个 MainActor 上。原 310 个核心测试保留名称与生命周期，按业务拆成 12 个测试扩展文件，共用独立夹具。

同一规模下的续测（Debug 单次观测）：

| 指标 | 旧路径 | 新路径 |
| --- | ---: | ---: |
| 三账户每轮写入量 | 13,861,968 字节 | 197,676 字节（减少 98.6%） |
| 三账户编码/后台准备 | 主线程 JSON 编码约 253 毫秒 | 后台准备约 13–16 毫秒 |
| 三账户列表读取 60 次 | 每次重新派生和排序 | 合计派生 3 次、排序 3 次 |
| 两个场外账户、三个去重代码 | 各账户分别请求 | 1 次批量请求 |

后台准备时间包括摘要、编码与临时文件写入，最后提交仅执行原子改名；此测量不代表真实 UI 帧率。新增恢复边界测试曾产生 5 个失败断言，分别暴露账户目录重叠以及中断日志未阻止刷新，均在修复后转绿。随后增加符号链接越界和目标遗留导入日志用例，先记录 3 个失败断言，再补齐目标目录及恢复前检查。

## GitHub issue 排查

- [#3 多账户支持](https://github.com/iamzjt-front-end/fund-pulse/issues/3)：已由 `7217ca3` 实现，并在 [v1.0.59](https://github.com/iamzjt-front-end/fund-pulse/releases/tag/v1.0.59) 发布。账户隔离、汇总、切换与持久化测试通过，已于本轮按已完成关闭并核验 GitHub 状态。这里的支持是独立本地账户管理，不代表支付宝、天天基金或雪球账号自动同步。
- [#2 闪退和收益展示](https://github.com/iamzjt-front-end/fund-pulse/issues/2)：确认资源查找与发布包目录不匹配。SwiftPM 命令行生成的 `Bundle.module` 查找应用根目录和构建机器路径，而发布脚本放在 `Contents/Resources`，用户机器会遇到 `fatalError`。新增不依赖开发机路径的可失败资源解析，缺失时走现有占位 UI。独立编译的探针应用移动、更名后，三个二维码资源都可解码；“关于”“支持”页面通过真实 NSHostingView 在深浅外观下渲染，截图复核资源显示正常。根据截图份额 47.92、成本 2.4373、正式净值 1.6772 建立回归用例，当前持仓收益为 -36.423992、收益率约 -31.19%；无需改为盘中估值计算。原报告的零收益现象在这组输入下没有复现，断网保值及正式净值分离由本轮其他回归覆盖。该报告记录发布前验证，发行验证与 issue 最终处理结果见对应 GitHub 页面。
